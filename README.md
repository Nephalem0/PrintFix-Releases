# PrintFix downloads

Portable Windows x64 printer troubleshooting utility.

Download the executable from [Releases](../../releases). No separate .NET installation is required; supported printer driver packages are downloaded on demand.

Early-access builds are intended for authorized IT support and testing. Physical printer tests and full Windows client coverage are not yet complete. Each release includes a SHA-256 checksum; the checksum is not a code-signing certificate.

This repository is for binary distribution only.
